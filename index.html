SECAPMS — System Architecture & Data Flow

AMBULANCE UNIT

Location / Priority Source

Sends emergency vehicle position and priority information toward the coordination layer.

➔
COORDINATION LAYER

Cloud / Web Platform

Evaluates route and junction information and forwards priority commands to the relevant traffic controller.

➔
TRAFFIC JUNCTION

Embedded controller represents the traffic-signal priority and emergency-corridor actuation layer.
