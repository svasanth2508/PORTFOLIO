## 🌟 Overview

Welcome to the official source repository for **Vasanth S's Interactive Portfolio & Telemetry Terminal**. This web application highlights hardware-to-cloud engineering projects, research achievements, full-stack software development, and the flagship **SECAPMS** (Smart Emergency Corridor & Ambulance Priority Management System) developed for the **Smart India Hackathon (SIH)**.

Built with pure, modular HTML5, CSS3 CSS Variables, and modern JavaScript (ES6+), the application delivers zero-lag 60fps performance, custom canvas particle mechanics, real-time scroll & coordinate telemetry, light/dark theme switching with WCAG AA compliance, direct multi-channel communication (Email & WhatsApp), and a built-in instant Resume exporter.

### 📡 1. SECAPMS Interactive Architecture Modal

### 📊 2. Live Telemetry HUD Bar
- **Mouse Coordinate Telemetry**: Live cursor tracking ($X, Y$).
- **Precision Scroll Position**: Displays exact pixel displacement and percentage ($0px - 100\%$).
- **Active Section Detector**: Dynamically highlights current viewport section (`#hero`, `#about`, `#secapms`, `#projects`, `#skills`, `#contact`).

- Custom HTML5 Canvas background engine with interactive node proximity links, pulse vectors, and mouse repulsion physics.

- High-contrast, glowing cyberpunk dark theme and ultra-clean light mode.
- Optimized CSS variable cascading ensuring **100% legibility** across both light and dark modes (no invisible text or unreadable badges).
