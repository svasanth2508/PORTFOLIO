## What makes this portfolio different?

This portfolio is structured as an **Engineering Mission Control** experience.

Instead of a standard:

`Hero → Skills → Project Cards → Contact`

layout, the site uses:

- an engineering **System Map**
- project **case-study inspection drawers**
- a `Ctrl + K` **command palette**
- dynamic engineering **HUD telemetry**
- an **Engineering Build Log**
- skills connected directly to the projects where they were used
- project limitations and technical decisions shown openly
- a restrained technical UI rather than a gaming/cyberpunk interface

## Local Development

```bash
git clone https://github.com/svasanth2508/PORTFOLIO.git
cd PORTFOLIO
```

Because the site is static, you can open `index.html` directly or run any local static server.

Example:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`
